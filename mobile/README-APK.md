# بناء APK لـ CivilDraft

1. ارفع المشروع (مع مجلدي `mobile/` و`.github/`) إلى مستودع GitHub.
2. من المستودع: تبويب **Actions** ← **Build Android APK** ← **Run workflow**.
3. بعد نحو 5–10 دقائق افتح التشغيل المكتمل ونزّل **CivilDraft-apk** من قسم Artifacts (ملف ZIP بداخله `app-debug.apk`).
4. انقله للهاتف وثبّته (فعّل «التثبيت من مصادر غير معروفة» إن طُلب).

ملاحظات:
- التطبيق كله داخل الـ APK ويعمل من أول مرة بلا إنترنت (عدا ميزات الذكاء الاصطناعي).
- أي تحديث للتطبيق يتطلب بناء APK جديد وتثبيته فوق القديم.
- هذا APK تجريبي (debug) للتثبيت المباشر. للنشر في Google Play يلزم توقيع release بمفتاح خاص.
- بيانات المشاريع محفوظة داخل التطبيق على الهاتف؛ لا تحذف بيانات التطبيق قبل تصدير نسخة احتياطية.
